## Фронтенд-разработчик: JavaScript, TypeScript, React

**Технологии и инструменты:**
*   **Стек:** HTML, CSS, JavaScript, TypeScript, React, React Router, Redux, Storybook
*   **Инструменты разработки:** Git, Vite

**Навыки и опыт:**
*   **Вёрстка и JavaScript:** Уверенно владею семантической HTML-вёрсткой и современным CSS (Flexbox, Grid). Хорошо понимаю основы языка JavaScript: работу с DOM, событиями, асинхронностью (Promises, async/await) и ES6+ синтаксисом.
*   **React и экосистема:** Имею базовый практический опыт создания интерфейсов на React (функциональные компоненты, хуки). Знаю, как организовать навигацию с помощью React Router и управлять состоянием приложения через Redux.
*   **TypeScript и UI:** Понимаю основы типизации в TypeScript (интерфейсы, типы, дженерики на базовом уровне). Умею разрабатывать и документировать переиспользуемые UI-компоненты в изоляции с помощью Storybook.
*   **Инструментарий:** Использую Git для контроля версий (ветвление, коммиты, работа с удаленным репозиторием) и Vite как быстрый сборщик для настройки и запуска проектов.
